# Taxman game

This is an implementation of the Taxman Game. This version includes a playable version and a bot who tries to get the best score using heuristics. 

## Characteristics

The program has two different versions to play.
* You choose the quantity of numbers from 1 to N. Then, you have to try to get the highest sum of numbers knowing that the factors will be taken by the Taxman.
* You choose the quantity of number from 1 to N. Then the bot gives you a solution after using an algorithm using a heuristic search. The algorithm is quite simple so it can be improved using different algorithms and heuristics.

## How to use it

There is only one python file, no external libraries are used, so you only need Python.  
You can clone the repository or download the python file.

## Contributing

The bot currently uses a basic heuristic, so this project is open to improvements. If you have any idea to optimize the algorithm you are free to contribute.
